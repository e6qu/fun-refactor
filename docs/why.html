Design

Every answer carries
how it was reached.

A refactoring tool that resolves a reference wrongly edits the wrong code, and the result usually compiles. This one attaches the resolution rule to every answer and rewrites only the two strongest tiers.

The alternatives

Find-and-replace covers every language and parses none. It renames the string in a comment, a substring inside another identifier, and the same-named field on an unrelated type.

A language server covers one language and stops at its edge: not Helm charts, Terraform modules or stylesheets, and not a file that does not currently compile.

This tool

One index across sixteen languages, built from syntax and not from types. Each reference is resolved by a specific rule — the scope chain, an import, the enclosing package — and which rule answered is attached to the answer.

It rewrites the references it resolved exactly or through an import, and lists the rest: weakly resolved sites, names appearing in strings, files that did not parse. Output is a diff plus that list.

Defects found by running it on real repositories

Each of these was in this tool, produced output that parsed, and was found by running it over an existing codebase instead of a fixture.

A guard clause that moved code out from under its guard

Go's grammar puts a statement_list between a block and its statements. Counted as a statement, it made every block look like a block of one — so the check "is this if the last thing here?" passed for an if with code after it, and the rewrite hoisted that code out from under the condition guarding it.

The result parses. No syntax check catches it. Over 250 files of helm's pkg/services: 1,258 of 1,498 applications were wrong — 84%. After the fix those are refused and the remaining 240 apply.

A de Morgan rewrite that dropped its own brackets

!(a && b) is one operand; !a || !b is two, and the brackets that held it together left with the negation. Inside another operator, x && !(a && b) became x && !a || !b: valid, and a different program.

References that were never found at all

A Go package is a directory — a function in one file is called from the next with no import and no qualifier. Only Terraform was treated that way, so fr refs returned zero for symbols helm calls from the file next door. Dead-code analysis reported 238 internal Go symbols as dead where 47 are. A rename rewrote the definition and listed the call sites it could not see as merely "unresolved".

That last one reported the gap instead of rewriting wrongly. It was still a bug, and it is fixed.

What it is measured on

1,376 tests, with clippy at -D warnings on every pull request
16,525 Grafana files parsed in 10.9s — 13 languages, one index
0 capability × language pairs marked "refused"; the other 112 are not applicable, with a reason

The capability matrix is computed by asking each refactoring's own predicate, not maintained by hand — because the hand-written version drifted twice, once hiding 27 cells that had never been built and once publishing six working ones as refused.

Where it fits

Not a replacement for rust-analyzer or gopls. They have types; this has syntax, and syntax stops at the point where a receiver's type would tell you which method you meant. When it reaches that point it says field-based and leaves the line alone.

What it has that they do not:

  • One index over the whole repository, whatever the file is written in.
  • Configuration as a first-class language — a Helm values key knows which templates read it, and a rename moves them.
  • Answers that survive a file that does not compile, because it never needed the compiler.
  • An explicit account of what it did not do, every time.
