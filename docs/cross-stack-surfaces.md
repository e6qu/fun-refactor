# Cross-stack surface model

`fr project technologies` identifies the thirteen requested host, framework, styling and embedded
language surfaces. It always returns the complete taxonomy and attaches bounded source-free
evidence only to surfaces observed in the selected revision and scope.

`fr project styles` builds a source-level relationship model. CSS selector declarations become
named definitions. Direct quoted `class` and `className` values in HTML, JSX and TSX become one row
per token. A unique captured definition resolves the use; duplicate definitions remain ambiguous.
An otherwise unresolved literal is a Tailwind utility candidate only when its nearest captured npm
package declares Tailwind CSS. JSX string expressions are literals. Template interpolation and
other computed forms become gaps.

The style reader does not evaluate CSS nesting, the cascade, specificity, Tailwind configuration or
generated output. Those limits appear in each affected row. Class names are bounded; arbitrary HTML,
JSX and CSS source is absent. Source handles provide the explicit next disclosure step.

`fr project diagrams` reports each Markdown document and its ATX heading hierarchy. Mermaid fences
attach to the nearest preceding heading. Named nodes and supported edges attach to the fence, with
edge rows referring to their node IDs. Diagram labels and sequence messages are omitted. Unknown
diagram kinds, unclosed fences and unmodeled Mermaid lines remain gap rows rather than guessed graph
semantics. Per-diagram node and edge limits report exact omissions.

The style classification and generic surface-bound functions are anchored to `FrKernels.Surface`.
Lean proves finite style result bounds, unique-definition priority, Tailwind's zero-definition
condition, and exact emitted/omitted partitioning. Shared executions compare the Rust and Lean
functions. CSS, HTML, JSX, Markdown and Mermaid recognition remains parser and fixture tested.

`fr project disclose HANDLE --view project` commits four branches under one
`fr-cross-stack-project-1` value: technologies, applications, styles and documents/diagrams. The
initial response contains no source and always catalogs the branches. Each returned action retains
the response ceiling, profile, target and revision. Individual facts keep exact source handles.
The generic Python Merkle pack and lazy restore functions can persist any completely revealed
branch by `object_digest` without learning a separate surface schema.
