Refactoring that tells you
what it could not prove.

Rename a symbol across Go, TypeScript, Rust, Python and a Helm chart at once. Each reference it finds carries the evidence that found it. The tool rewrites the references it can justify and hands you the rest as a list.

Every reference carries its resolution tier

A textual rename covers every language and proves nothing. A compiler-backed one proves everything and covers one language. This tool resolves what the syntax settles, labels each answer with the rule that produced it, and rewrites the two strongest tiers.

It rewrites exact and import-qualified. It hands you field-based and name-only to check yourself. It guesses nothing.

It reads the configuration too

A Helm chart pairs a values file with the templates that read it, a dataflow no compiler sees. Rename a values key and the templates that use it move with it. {{ .Release.Name }} stays as written, because it spells the same word and means a different thing.

alpine chart
fr rename testcharts/alpine/values.yaml:1:1 appName
-  name: "{{.Release.Name}}-{{.Values.Name}}"
+  name: "{{.Release.Name}}-{{.Values.appName}}"
-    values: {{.Values.Name}}
+    values: {{.Values.appName}}
