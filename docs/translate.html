Translation

Typed Python, written as TypeScript. And back.

The two languages closest to each other get the closest translation: list[str] is string[], dict[str, int] is Record<string, number>, Optional[T] is T | null, a @dataclass is an interface, an f-string is a template literal, a comprehension is a .filter() chain, and await means the same thing in both. Six languages go through the same shared meaning — Rust, Go, Java, Python, TypeScript and Zig — so every one of the thirty ordered pairs is a reader and a writer rather than a translator of its own.

Generated  Every result below is what fr translate actually produced, captured by cargo test --test site_data. The first two carry nothing over as a comment in either direction — the strongest claim any pair in this tool makes. The rest are real code from real projects, and say exactly where the translation stops being one. Zig is the far end of the range: no new, no exception, no interpolated string and no block comment at all. The Next.js route is a different kind of crossing again: what it preserves is an API contract, not a signature.

What is being promised

The signature is the contract. Every parameter, in order, with its type and the return type, carried exactly — only the spelling changes, to the target's convention. Where a type has no counterpart it is written through by name and counted, because quietly substituting a type is how a signature stops meaning what it said.

Names take the target's convention, and only the file's own. user_create is userCreate in TypeScript, at its declaration and at every use. A name the module does not declare — db.users.find, a library function — is left exactly as written, because re-casing it would rename somebody else's API.

Nothing goes missing quietly. Ownership, decorators, generators, destructuring and error propagation have no general translation, and a guess would be worse than a gap. Each one is carried into the output verbatim, inside a comment, under a marker, and counted in the report. The result is a file you finish, not one you have to diff against the original to find out what was lost.

Where it stops

It is not a compiler, and the result is a draft. The FastAPI backend at the bottom is the honest picture: five of its five signatures mention types from libraries this tool has never heard of, and Python's keyword-only parameters have no TypeScript spelling at all — so the types cross, and the report says that callers will write the call differently. That sentence is worth more than a silently plausible file.
