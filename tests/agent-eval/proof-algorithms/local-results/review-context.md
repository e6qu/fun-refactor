# What these runs establish

All twenty original sessions ran once. Independent checking accepted all eight
patches delivered to the required location. Twelve complete attempts timed out.
The complete 150-second limit included preparation, tools, checks and accounting.
Three refused launches happened before any model session began; those original
unstarted slots waited for another project's use of the shared workstation guard.
No closed model slot was rerun. Raw local records remain private.

The declaration comparison gave GLM zero completions in each condition. Kimi
completed one supplied-declaration session and neither selection session.
That is inconclusive with two repetitions.

In the presentation comparison, Luna completed both repetitions in both formats.
Kimi completed both graph sessions and one checklist session. GLM completed neither.
One GLM session encountered a confirmed fr reader defect, so its comparison is
marked uncertain. The recorded provider-error count and measured system sleep
were zero; the uncertainty here concerns the reader.

These runs establish no general graph advantage. They compare two layouts of
the same advice. They do not test searching a graph of possible proof steps.
No profile met the preregistered two-versus-zero rule for a transfer comparison.
Accumulator-based list reversal remains reserved. Repeated command mistakes and
library mismatches do not yet justify an automatic proof-backtracking controller.

Several failures suggest concrete repairs. Agents repeatedly added unsupported
options, discarded useful error lines, or edited both proofs before checking one.
A repeated write could also return an empty diff because the proof was already
present. One Kimi session passed both draft checks but never saved and delivered
the final result. Another passed both proofs and the package check, then wrote
the patch to the parent directory. Its exact diff is preserved separately in
[the misplaced-submission record](misplaced-submission/summary.json); it remains
a failed complete attempt and does not add a canonical submission.

A separate no-model control exposed the reader defect. Lean accepts a multiline
lambda used to build the GCD induction proof, while the measured fr reader rejects
it before Lean runs. That control supplies a reference proof; it does not credit
the failed agent draft, which also contained Lean errors. Repair and replay the
reader separately, keeping every original outcome unchanged.

Total elapsed time includes the outer guard. Step clocks use recorded tool-call
completion times relative to controller entry; a batched call gives an upper bound
for its steps. Missing clocks remain unknown. Time outside recorded tool calls
also includes CLI overhead and unfinished work. These runs provide no ordinary-Lean
overhead baseline, billing measurement or proof about a Rust/Python translation.
M3 remains open.
