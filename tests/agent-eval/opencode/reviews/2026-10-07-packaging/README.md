# Whole packaging task review with a smaller client catalog

This fresh collection freezes one review each for configured Kimi K3 and GLM
5.3 Flash. Both receive the complete requirement, eight-case grader, reference
filter and source identities prepared in `2026-10-06-packaging-inputs`.

The catalog experiment and one guarded workstation control passed before this
collection was frozen. The collector binds that evidence, its own implementation
and the exact empty catalog. Each capture uses the override only in its process
environment. Plans and inputs must be committed before either model runs.

The limits remain 120 seconds, 20 CPU seconds, 768 MiB aggregate sampled RSS,
16 MiB disk growth and 1 MiB transcript. The outer workstation guard also applies.
The first resource-limit failure permanently stops this collection. Models may
read through ordinary tools or `fr`; they cannot edit or execute candidate code.

Review findings require independent verification. Empty findings do not accept
the task. This collection does not run the four code-change pilot attempts.
